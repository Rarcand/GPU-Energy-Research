# Historical project files

The simulator submodules in `tools/` and the original transfer experiment in
`scripts/` and `slurm/` predate the five-GPU workshop study. The active
collectors and CPU replay run independently of these tools.

The full earlier research checkout, including dated timing diagnostics and
raw job output, is archived separately on the research Mac. `archive/` is
ignored by Git for any local archive link or restored files.
